## ハードウェア

| 部位 | 仕様 |
| --- | --- |
| 台車 | 差動二輪 |
| 胴体 | 昇降機構 |
| 腕 | グリッパ付きの双腕 |
| 頭部 | パン・チルト。Intel RealSense D435i（RGB-D カメラ）を搭載 |
| アクチュエータ | Feetech STS3215 シリアルバスサーボ。ESP32 のサーボドライバで駆動 |
| 計算機 | NVIDIA DGX Spark（視覚言語モデル、セグメンテーション、音声認識）と NVIDIA RTX 5090 搭載のノート PC |

機構はオープンソースのロボット [Astra](https://github.com/trail-club/Astra_Hardwares) をもとにしています。

## ソフトウェア

Ubuntu 24.04 と ROS 2 Jazzy で動き、Gazebo Harmonic で開発・検証しています。
パッケージと使い方は [ソフトウェア](/ja/software/) を見てください。

## できること

- ナビゲーション: 地図作成、自己位置推定、経路計画（slam_toolbox、AMCL、Nav2）
- マニピュレーション: 腕の動作計画（MoveIt 2）
- 認識: 物体のセグメンテーションと認識、人の検出、物を置ける面の検出
- 人との対話: 音声認識と音声合成
- タスク実行: タスクをサブゴールに分け、チェックポイントと巻き戻しを持たせて実行。Web GUI で監視
